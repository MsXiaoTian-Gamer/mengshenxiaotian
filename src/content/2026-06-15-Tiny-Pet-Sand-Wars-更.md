## 🗺️ 超大背景地图

现在主战场后面多了一大片远景地形，画面看起来更有层次感了！

- 背景地图比战斗区大上好多倍，一眼望去真的像在沙漠里

- 地形会自动生成岛屿、草地、水域，每局都独一无二

- 远景会自然变淡，不会抢视线

- 地图周围还有可爱的装饰边框

整套 UI 走的是暖萌路线，配色软软的甜甜的～

## ⚔️ 12 把武器随你挑

近战武器会围着你转，远程武器自动帮你打最近的敌人。

**近战（贴身肉搏）：**

- 生锈小刀 —— 免费初始武器

- 风暴战斧 —— 大斧头，伤害高

**远程（哒哒哒自动射击）：**

- 砾石冲锋枪、双牙冲锋枪 —— 射速快

- 沙畔手枪、商队手枪 —— 手感佳

- 沙线步枪、鬃刺步枪 —— 伤害稳定

- 穿日狙击枪 —— 一枪一个

- 散射手炮、沙暴发射器 —— 爆发力强

- 水晶光束 —— 高射速激光

武器还有品质区分：**普通、稀有、史诗、传说**，越往后越帅，金色传说谁不爱呢？

### 支援武器

多出来的武器不会闲着，它们会变成小跟班围着你自动打怪！升级后伤害越来越高，颜色也越来越金闪闪。

### 子弹特效

毒液弹会让敌人持续掉血，冰弹能减速，雷弹有额外爆发。打到敌人还有华丽的爆炸特效，敌人攻击前也会有明显的预警提示～躲起来很方便。

## 👾 怪物大军

一共 12 种怪物，各有各的绝活：

| 怪物 | 特点 |

|------|------|

| 沙行虫 | 普通小怪，会冲过来咬你 |

| 尘奔者 | 跑得飞快，突然冲刺撞你 |

| 鬃刺吐息 | 远远地吐口水打你 |

| 日光虫群 | 一群蜂拥而上 |

| 甲壳蛮兽 | 血超厚的大坦克 |

| 琥珀哨兵 | 一次射两发 |

| 沙之幻影 | 会隐身！突然现身冲刺 |

| 甲壳分裂体 | 打死会分裂成两只小的 |

| 沙丘修补匠 | 会奶其他怪物 |

| 风暴精英 | 一次射三发 |

怪物会随游戏时间越来越多种类，也越来越强。打到 12 分钟就会出现最终 Boss，打赢就胜利啦～

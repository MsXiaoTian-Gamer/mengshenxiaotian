# Unity 零基础入门指南

> 这份指南是写给完全没接触过编程和游戏开发的人的。
> 不需要任何基础，只需要一台电脑和想做游戏的心。

---

## 一、Unity 是什么

Unity 是一个**做游戏的工具**。

你不需要从零造引擎，Unity 帮你处理了渲染、物理、声音这些底层的东西。你只需要：
- 把东西摆到场景里
- 写一些简单的代码告诉它们"怎么动"

很多你玩过的游戏都是用 Unity 做的：《原神》《王者荣耀》《空洞骑士》《人类一败涂地》……

## 二、装环境

### 2.1 安装 Unity Hub

去 [unity.com](https://unity.com) 下载 **Unity Hub**。

Unity Hub 是一个管理器，帮你装不同版本的 Unity、创建项目、打开项目。

### 2.2 安装 Unity 编辑器

打开 Unity Hub → 左侧点"安装" → 点"安装编辑器" → 选最新的**LTS 版本**（长期支持版，稳定）。

安装时勾选：
- **Microsoft Visual Studio**（写代码用的编辑器）
- 如果你想做 2D 游戏，勾选 2D 模块
- 如果你想做 3D 游戏，勾选 3D 模块

### 2.3 创建第一个项目

Unity Hub → 左侧点"项目" → "新项目" → 选"3D"模板 → 起个名字 → 点"创建项目"。

等一会儿，Unity 编辑器就打开了。

## 四、什么是编程

编程就是**写指令告诉电脑做什么**。

就像你写菜谱：
1. 拿一个鸡蛋
2. 打到碗里
3. 搅拌
4. 倒进锅里

电脑不会自己思考，你告诉它一步，它就做一步。

在 Unity 里，你写的是 **C# 语言**（读作"C sharp"）。不用担心，不需要学完所有语法，只需要学会最常用的几个东西。

## 五、C# 最基础的几个概念

### 5.1 变量 —— 存东西的盒子

变量就是一个**有名字的盒子**，里面可以放数据。

```csharp
int age = 18;           // 盒子叫 age，里面放了数字 18
float weight = 65.5f;   // 盒子叫 weight，里面放了小数 65.5
string name = "小明";   // 盒子叫 name，里面放了文字
bool isAlive = true;    // 盒子叫 isAlive，里面放了"是或否"
```

- `int` = 整数（1, 2, 100, -5）
- `float` = 小数（3.14, 0.5）注意要加 f
- `string` = 文字（用双引号包起来）
- `bool` = 对或错（true 或 false）

### 5.2 方法 —— 一串指令打包在一起

方法就是把几步操作**打包成一个动作**，起个名字。

```csharp
void SayHello()    // 定义一个叫 SayHello 的方法
{
    Debug.Log("你好！");   // 打印一句话到控制台
}
```

- `void` = 这个方法做完不需要返回结果
- `()` = 里面可以放参数（后面会讲）
- `{}` = 大括号里面是具体要做的事

调用方法就是：写它的名字 + 括号。

```csharp
SayHello();   // 执行这个方法，控制台会打印"你好！"
```

### 5.3 条件判断 —— 如果……就……

```csharp
int score = 80;

if (score >= 60)
{
    Debug.Log("及格了！");
}
else
{
    Debug.Log("没及格……");
}
```

意思：如果分数大于等于 60，打印"及格了"，否则打印"没及格"。

### 5.4 循环 —— 重复做某事

```csharp
for (int i = 0; i < 5; i++)
{
    Debug.Log("第 " + i + " 次");
}
```

意思：让 i 从 0 开始，每次加 1，直到 i 等于 5 停止。一共会打印 5 次。

### 不用全记住

现在只需要**大概理解**这些是什么意思就行。后面写代码的时候会反复用到，用多了自然就记住了。

## 六、Unity 里最重要的概念：GameObject 和 Component

### 6.1 GameObject —— 游戏里的"东西"

你在场景里看到的一切都是 **GameObject**（游戏对象）：
- 一个方块是 GameObject
- 一盏灯是 GameObject
- 一个摄像机是 GameObject
- 一个 UI 按钮也是 GameObject

### 6.2 Component —— 给东西"加能力"

GameObject 本身什么都干不了。它的能力来自挂在它身上的 **Component**（组件）。

就像手机本身只是个壳，装了摄像头能拍照，装了喇叭能放音乐。

一个方块的组件：

| 组件 | 作用 |
|------|------|
| Transform | 决定它在哪里、转了多少度、多大 |
| Mesh Renderer | 让它能被看见（有颜色有形状） |
| Box Collider | 让它有碰撞体积（能被撞到） |
| Rigidbody | 让它受物理影响（会掉下来） |

**选中场景里的方块，在 Inspector 窗口就能看到它身上有哪些组件。**

### 6.3 脚本也是一种组件

你写的 C# 脚本，本质上也是一个 Component，挂到 GameObject 上就能控制它。

## 八、理解 Start 和 Update

```csharp
void Start()
{
    // 游戏开始时执行一次
}

void Update()
{
    // 每一帧都执行（大约每秒执行 60 次）
}
```

- **Start**：适合做初始化，比如"游戏开始时打印一句话"
- **Update**：适合做持续的事，比如"每帧检测玩家有没有按键"

试试看：

```csharp
void Update()
{
    Debug.Log("我在一直执行！");
}
```

运行后你会发现 Console 一直在刷屏。**记得改回来或者删掉**，不然会卡。

## 九、让东西动起来

### 9.1 最简单的移动

```csharp
using UnityEngine;

public class MoveCube : MonoBehaviour
{
    void Update()
    {
        // 每帧向前移动一点点
        transform.Translate(0, 0, 0.01f);
    }
}
```

- `transform` = 这个对象的 Transform 组件（位置、旋转、缩放）
- `Translate(0, 0, 0.01f)` = 沿 Z 轴移动 0.01

运行后方块会一直往前走。

### 9.2 加上键盘控制

```csharp
using UnityEngine;

public class MoveCube : MonoBehaviour
{
    public float speed = 0.05f;

    void Update()
    {
        float h = Input.GetAxis("Horizontal");  // 左右（A/D 或 ←/→）
        float v = Input.GetAxis("Vertical");    // 上下（W/S 或 ↑/↓）

        transform.Translate(h * speed, 0, v * speed);
    }
}
```

运行后，用 **WASD** 或**方向键**就能控制方块移动了。

### 9.3 为什么要乘以 Time.deltaTime

上面的代码在不同电脑上速度会不一样（帧率高的快，帧率低的慢）。

加上 `Time.deltaTime` 就能统一速度：

```csharp
transform.Translate(h * speed * Time.deltaTime, 0, v * speed * Time.deltaTime);
```

`Time.deltaTime` = 上一帧到现在过了多少秒（大约 0.016 秒）。

乘以它之后，不管帧率多少，**每秒移动的距离是一样的**。

## 十、物理：让东西会掉下来

### 10.1 加 Rigidbody

1. 选中方块
2. 在 Inspector 点 "Add Component"
3. 搜索 **Rigidbody**，添加

运行，方块会掉下去！因为 Rigidbody 让它受重力影响了。

### 10.2 加地面

1. Hierarchy 右键 → 3D Object → **Plane**
2. 把它放到方块下方
3. 调整位置，让方块在地面上方

运行，方块掉到地面上停住了。因为 Plane 自带碰撞器，方块撞到了它。

### 10.3 用代码控制物理对象

```csharp
using UnityEngine;

public class PhysicsMove : MonoBehaviour
{
    private Rigidbody rb;
    public float speed = 5f;

    void Start()
    {
        rb = GetComponent<Rigidbody>();  // 获取 Rigidbody 组件
    }

    void FixedUpdate()  // 物理操作放 FixedUpdate
    {
        float h = Input.GetAxis("Horizontal");
        float v = Input.GetAxis("Vertical");

        rb.velocity = new Vector3(h * speed, rb.velocity.y, v * speed);
    }
}
```

- `GetComponent<Rigidbody>()` = 获取这个对象上的 Rigidbody
- `FixedUpdate` = 固定时间间隔调用，适合物理操作
- `rb.velocity` = 设置速度（不要直接改 transform）

## 十一、碰撞检测

### 11.1 碰撞器（Collider）

每个能碰撞的对象都需要一个 **Collider**（碰撞器）：
- Box Collider = 方形碰撞器
- Sphere Collider = 球形碰撞器
- Capsule Collider = 胶囊碰撞器

Cube 自带 Box Collider，Sphere 自带 Sphere Collider。

### 11.2 检测碰撞

```csharp
using UnityEngine;

public class CollisionDetector : MonoBehaviour
{
    // 碰到东西时自动调用
    void OnCollisionEnter(Collision collision)
    {
        Debug.Log("撞到了：" + collision.gameObject.name);
    }
}
```

### 11.3 触发器（Trigger）

有时候你不想让对象"挡住"，而是想让对象"穿过"但能检测到（比如捡金币）。

1. 选中金币的 Collider
2. 在 Inspector 里勾选 **Is Trigger**

```csharp
void OnTriggerEnter(Collider other)
{
    Debug.Log("有东西进来了：" + other.name);
    Destroy(gameObject);  // 销毁自己（金币消失了）
}
```

**碰撞条件：** 至少一方有 Rigidbody，碰撞检测才能工作。

## 十二、预制体（Prefab）

### 12.1 什么是预制体

假如你做了一个金币，游戏里需要 100 个金币。你不可能手动摆 100 次。

**预制体**就是一个"模板"，你可以用它复制出很多个。

### 12.2 怎么做

1. 在场景里把金币配置好（加模型、加碰撞器、加脚本）
2. 把它从 Hierarchy **拖到 Project** 窗口
3. 预制体就创建好了
4. 场景里那个金币变成了蓝色，表示它是预制体的实例

### 12.3 代码生成预制体

```csharp
using UnityEngine;

public class Spawner : MonoBehaviour
{
    public GameObject coinPrefab;  // 在 Inspector 里拖入预制体

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            Instantiate(coinPrefab, transform.position, Quaternion.identity);
        }
    }
}
```

- `public GameObject coinPrefab` = 声明一个变量，在 Inspector 里可以拖拽赋值
- `Instantiate()` = 复制出一个新的
- 按空格键就会生成一个金币

### 13.3 按钮

1. Hierarchy 右键 → UI → **Button**

public Button startButton;  // 在 Inspector 里拖入按钮

void Start()
{
    startButton.onClick.AddListener(OnStartClick);

void OnStartClick()
{

}

## 十四、协程：延迟执行

有时候你想"等 2 秒再做某事"，用协程：

```csharp
using UnityEngine;
using System.Collections;  // 要加这个

public class Timer : MonoBehaviour
{
    void Start()
    {
        StartCoroutine(WaitAndPrint());
    }

    IEnumerator WaitAndPrint()
    {
        Debug.Log("开始等待...");
        yield return new WaitForSeconds(2f);  // 等 2 秒
        Debug.Log("2 秒到了！");
    }
}
```

- `IEnumerator` = 协程的返回类型
- `yield return new WaitForSeconds(2f)` = 暂停 2 秒再继续

## 十六、调试：找 Bug

### 16.1 看 Console

报错时 Console 会显示红色文字，告诉你：
- 哪个脚本出错了
- 第几行出错了
- 什么类型的错误

**双击红色错误信息，会自动跳到出错的代码。**

### 16.2 常见错误

| 错误 | 意思 | 怎么解决 |
|------|------|----------|
| NullReferenceException | 你用了一个"空"的东西 | 检查变量有没有赋值 |
| 一堆红色波浪线 | 语法写错了 | 检查括号、分号、拼写 |
| 脚本不生效 | 忘记挂到对象上 | 把脚本拖到 Inspector |

### 16.3 用 Debug.Log 调试

不确定某个变量的值？打印出来看：

```csharp
Debug.Log("当前分数：" + score);
Debug.Log("玩家位置：" + transform.position);
```

## 十七、第一个小项目：滚球吃方块

现在你已经学了足够的知识，来做一个小游戏吧！

### 目标
- 一个球，用键盘控制滚动
- 地上散落着方块
- 球碰到方块，方块消失，分数加 1
- 屏幕上显示分数

### 步骤

**第 1 步：搭场景**
1. 创建 Plane 做地面
2. 创建 Sphere 做玩家球
3. 创建几个 Cube 散落在地面上

**第 2 步：让球能滚动**
1. 给球加 Rigidbody
2. 给球加脚本，用 WASD 控制移动

```csharp
using UnityEngine;

public class PlayerBall : MonoBehaviour
{
    private Rigidbody rb;
    public float speed = 5f;

    void Start()
    {
        rb = GetComponent<Rigidbody>();
    }

    void FixedUpdate()
    {
        float h = Input.GetAxis("Horizontal");
        float v = Input.GetAxis("Vertical");
        rb.velocity = new Vector3(h * speed, rb.velocity.y, v * speed);
    }
}
```

**第 3 步：让方块能被吃**
1. 给方块加 Collider，勾选 Is Trigger
2. 给方块加脚本：

```csharp
using UnityEngine;

public class Coin : MonoBehaviour
{
    void OnTriggerEnter(Collider other)
    {
        if (other.CompareTag("Player"))
        {
            Destroy(gameObject);
        }
    }
}
```

3. 给球设置 Tag 为 "Player"（选中球 → Inspector 顶部 → Tag → Player）

**第 4 步：加分数 UI**
1. Hierarchy 右键 → UI → Text
2. 写一个分数管理器：

```csharp
using UnityEngine;
using UnityEngine.UI;

public class ScoreManager : MonoBehaviour
{
    public Text scoreText;
    private int score = 0;

    public void AddScore()
    {
        score++;
        scoreText.text = "分数：" + score;
    }
}
```

3. 在方块的脚本里调用 AddScore：

```csharp
void OnTriggerEnter(Collider other)
{
    if (other.CompareTag("Player"))
    {
        FindObjectOfType<ScoreManager>().AddScore();
        Destroy(gameObject);
    }
}
```

**第 5 步：运行测试**

点播放，用 WASD 控制球滚向方块，碰到后方块消失，分数增加。
